# ระบบปฏิบัติงาน 75 ชั่วโมง

เว็บ Node.js 24+ สำหรับนักศึกษา 15 คนและผู้ดูแล ข้อมูลอยู่ใน SQLite บนเซิร์ฟเวอร์เดียว นักศึกษาแต่ละคนบันทึก แก้ไข และลบรายการของตนเองได้ ผู้ดูแลดู dashboard รายเดือนและชั่วโมงสะสมทุกคน รวมทั้งแก้ไขรายการและจัดการบัญชี

## ทดลองในเครื่อง

1. ติดตั้ง Node.js 24 หรือใหม่กว่า ไม่ต้องติดตั้งแพ็กเกจ npm
2. คัดลอก `.env.example` เป็น `.env` และแก้ `ADMIN_PASSWORD`, `SESSION_SECRET`, `PUBLIC_ORIGIN` ให้ตรงกับ URL ที่เปิดจริง ตัวอย่างการสุ่ม secret: `openssl rand -hex 32`
3. รัน `npm start` แล้วเปิด URL ที่ตั้งไว้ สำหรับ MacBook ให้ตั้ง `PUBLIC_ORIGIN=http://localhost:3000` และ `BASE_PATH=` (ว่าง)
4. เรียก `npm test` เพื่อตรวจสิทธิ์นักศึกษา dashboard การบันทึก/แก้ไข การนับชั่วโมง และการป้องกันเวลาทับกัน

## บัญชีผู้ใช้

- ผู้ดูแลเข้าด้วยชื่อบัญชี `admin` และ `ADMIN_PASSWORD` ใน `.env`
- เมื่อเข้าหน้า dashboard ให้กด **สร้างบัญชี** ในแถวของนักศึกษา ระบบจะแสดงรหัสผ่านเริ่มต้นแบบสุ่ม **เพียงครั้งเดียว** ส่งรหัสให้นักศึกษาคนนั้นผ่านช่องทางส่วนตัว พร้อมรหัสนักศึกษาซึ่งใช้เป็นชื่อบัญชี
- นักศึกษาต้องเปลี่ยนรหัสผ่านเริ่มต้นก่อนใช้งาน จากนั้นจะเห็นและแก้ไขตารางของตนเองเท่านั้น
- ปุ่ม **ออกรหัสใหม่** ของผู้ดูแลจะยกเลิกรหัสเดิมและ session ที่เปิดอยู่ทันที ข้อมูลตารางงานไม่ถูกลบ
- การอัปเดตจากรุ่นก่อน: คัดลอก `.env` และโฟลเดอร์ `data` ไปยังโครงการรุ่นใหม่ ฐานข้อมูลจะเพิ่มตารางบัญชีอัตโนมัติ โดยรักษารายการปฏิบัติงานเดิม

## ติดตั้งบน witcha.dusit.ac.th

ผู้ดูแลเซิร์ฟเวอร์ต้องมีสิทธิ์ตั้งค่า DNS, HTTPS และ Nginx ของโดเมนนี้ ก่อนใช้ตัวอย่างด้านล่างให้ตรวจว่าโดเมนไม่ได้ให้บริการเว็บอื่นอยู่ และให้รวมเฉพาะ `location /75hour/` ในการตั้งค่าเว็บเดิม (ไฟล์ตัวอย่างแสดง server block เต็มเพื่อเป็นแนวทาง ไม่ควรทับการตั้งค่าเว็บเดิม)

1. คัดลอกโฟลเดอร์โครงการไปที่ `/opt/hours75`; สร้างผู้ใช้ระบบ `hours75` และโฟลเดอร์ `/var/lib/hours75` ที่เขียนได้เฉพาะผู้ใช้นี้
2. สร้าง `/etc/hours75.env` โดยตั้ง `ADMIN_PASSWORD`, `SESSION_SECRET`, `PUBLIC_ORIGIN=https://witcha.dusit.ac.th`, `BASE_PATH=/75hour`, `HOST=127.0.0.1`, `PORT=3000`, `DATA_DIR=/var/lib/hours75`; ให้ไฟล์อ่านได้เฉพาะ root และผู้ใช้ที่จำเป็น
3. ปรับ `deploy/hours75.service` ให้ตรงกับตำแหน่ง Node.js จาก `which node`, ติดตั้งเป็น systemd service แล้ว `systemctl daemon-reload && systemctl enable --now hours75`
4. ชี้ DNS ของโดเมนไปยังเซิร์ฟเวอร์ ออกใบรับรอง TLS และติดตั้ง `deploy/nginx.conf` หลังปรับเส้นทางใบรับรองให้ตรง ตรวจ `nginx -t` ก่อน reload
5. เปิด `https://witcha.dusit.ac.th/75hour/` แล้วเข้าหน้าเว็บด้วยรหัสผ่านผู้ดูแล ทดสอบบันทึกหนึ่งรายการแล้วตรวจยอดรายเดือนและยอดสะสม

สำรองข้อมูลไฟล์ `/var/lib/hours75/hours75.sqlite` เป็นประจำ โดยใช้กลไก SQLite backup หรือหยุดบริการก่อนคัดลอกเพื่อให้ไฟล์สำรองสอดคล้องกัน ไม่ควรเผยแพร่โฟลเดอร์ข้อมูลผ่านเว็บ

**ขอบเขตปัจจุบัน:** บัญชีนักศึกษาใช้รหัสนักศึกษาและรหัสผ่านที่ผู้ดูแลออกให้ ยังไม่เชื่อมระบบยืนยันตัวตนของมหาวิทยาลัยและยังไม่มีขั้นตอนอนุมัติงาน หากต้องใช้บัญชีมหาวิทยาลัยหรือหลักฐานยืนยันชั่วโมง ต้องเชื่อมระบบเหล่านั้นเพิ่มเติม
